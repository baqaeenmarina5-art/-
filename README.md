# 🌍 أصدقاء الأرض — لعبة تفاعلية لرياض الأطفال

لعبة تعليمية تفاعلية (HTML/CSS/JavaScript بدون أي مكتبات خارجية) مبنية على وحدات منهاج رياض الأطفال:
النباتات، وطني الأردن، أصدقاء الأرض، شكرًا روضتي — بالإضافة إلى عالم موسّع للرياضيات.

## 🎮 جرّبها مباشرة
افتح `index.html` في أي متصفح، أو فعّل **GitHub Pages** من إعدادات المستودع (Settings → Pages → Deploy from branch → `main` / root) وستحصل على رابط مباشر للعبة.

## 🗂️ محتوى اللعبة (21 مستوى موزّعة على 5 وحدات)

| الوحدة | المستويات |
|---|---|
| 🌱 النباتات | حروف عربية (ل، ز، ج) • English Letters (G, K) • أعداد 10-12 • عالم النبات |
| 🏛️ وطني الأردن | حروف عربية (ق، خ، غ) • English Letters (L, U) • أعداد 13-15 • معالم وطني |
| 🌍 أصدقاء الأرض | حروف عربية (ذ، ط، ك، ض) • English Letters (Y, W, X, Z) • أعداد 17-20 • أرضي الجميلة • حافظ على الأرض |
| 🎓 شكرًا روضتي | حروف عربية (ظ، هـ) • مهارات وقيم |
| 🔢 عالم الرياضيات | الجمع والطرح • الأشكال الهندسية • الأنماط • أكبر أو أصغر • ترتيب الأعداد • القفز بالعشرات |

كل مستوى يحتوي أسئلة متنوعة الأساليب (اختيار من متعدد، صح/خطأ، عدّ العناصر) مع تقييم بالنجوم (1-3) وتتبّع تلقائي للتقدّم.

## 🏗️ بنية المشروع

```
earth-friends-game/
├── index.html        # الهيكل العام للصفحة
├── css/
│   └── style.css      # كل التنسيقات والألوان والحركات
├── js/
│   ├── data.js         # بيانات الوحدات والمستويات والأسئلة (عدّلها لإضافة أسئلة جديدة)
│   └── app.js           # منطق اللعبة (العرض، التنقل، التقييم)
└── README.md
```

## ✏️ كيف أضيف سؤالًا أو مستوى جديدًا؟

كل التعديلات على المحتوى تتم في ملف `js/data.js` فقط — لا حاجة لمسّ باقي الملفات.

### إضافة سؤال إلى مستوى موجود
افتح `js/data.js`، وأضف عنصرًا جديدًا داخل مصفوفة `questions` الخاصة بالمستوى المطلوب. الأنواع المدعومة:

```js
// اختيار من متعدد
{type:'mcq', prompt:'نص السؤال؟', options:[
  {emoji:'🍎', text:'الإجابة الصحيحة', correct:true},
  {text:'إجابة خاطئة', correct:false}
]}

// صح أو خطأ
{type:'tf', prompt:'جملة للحكم عليها.', correct:true}

// عدّ العناصر
{type:'count', emoji:'⭐', count:14, options:[13,14,15]}
```

### إضافة مستوى جديد
أضف كائنًا جديدًا إلى مصفوفة `LEVELS` بنفس الشكل، مع `unit` يطابق أحد المفاتيح في `UNITS` (`u5`, `u6`, `u7`, `u8`, `math`) أو أضف وحدة جديدة بالكامل في `UNITS`.

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد إليه.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر **Deploy from a branch**، الفرع `main`، والمجلد `/ (root)`.
4. بعد دقيقة أو دقيقتين ستحصل على رابط مثل: `https://<username>.github.io/<repo-name>/`.
